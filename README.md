# SkyPlane Combat Re:verse

Модуль для Foundry VTT v13 и D&D 5e: лист неболёта с конструктором, сцена корабля из тайлов, регионов и стен, сцена боя двух кораблей с обстрелом, разведкой и ремонтом, активные эффекты отсеков.

- **ID:** `skyplane-combat-reverse`
- **Foundry:** v13 (проверено на 13.351), система `dnd5e`
- **Зависимость:** [socketlib](https://github.com/farling42/foundryvtt-socketlib)
- **Языки:** русский, английский (содержимое компендиумов — на русском)

## Установка

В Foundry: «Дополнения» → «Установить модуль» → поле «URL манифеста»:

```
https://github.com/Paragon-Re-verse/Skyplane-Combat-Reverse/releases/latest/download/module.json
```

Включите в мире модули SkyPlane Combat Re:verse и socketlib. Foundry проверяет обновления по этой же ссылке.

## Что внутри

| Часть | Что делает |
|---|---|
| Actor «Неболёт» | Лист с вкладками: Параметры, Конструктор, Системы, Экипаж, Описание, Журнал (только ГМ) |
| Item «Отсек» | Каталог отсеков в компендиуме «Отсеки неболёта» |
| Конструктор | Сетка до 14×8, проверка правил, перенос отсеков, стартовый набор, отмена Ctrl+Z |
| Экспорт и импорт | Корабль в JSON и обратно из меню заголовка листа (ГМ) |
| Активные эффекты | Эффекты отсеков каталога меняют прочность, вместимость, скорость, экономию, точность, урон, защиту, ремонт и разведку корабля, пока отсек цел |
| «Развернуть на сцену» | Сцена корабля: тайлы, регионы, стены, области параметров и описания |
| «Начать бой…» | Сцена боя двух кораблей, копирование токенов, разведка через радар |
| Панель боя ГМа | HP, флогистон, отсеки, дистанция, ручное раскрытие |
| Обстрел | Из окна отсека с огневой мощью: прицел по отсеку противника, проверка навыка dnd5e, окно урона dnd5e; урон в прочность и в HP отсека. Пушка стреляет раз за раунд трекера, трассер от пушки к цели |
| Особые пушки | Набор дистанций без штрафа; «Брызги» задевают соседние отсеки, «Зарядка» стреляет раунд спустя, «Залп» — каждая кость отдельный выстрел |
| Разведка | Член экипажа в радаре проходит проверку навыка — противник раскрыт, пока разведчик на посту |
| Ремонт | Расходник из инвентаря персонажа восстанавливает HP отсека |
| Права | Матрица «игрок × право» в настройках, действия игроков через socketlib |

Компендиум «SkyPlane: шаблоны кораблей» — шесть готовых неболётов: «Стриж» (курьер 9×3), «Ворчун» (грузовой барк 12×5), «Гарпия» (канонерка 10×4), «Левиафан» (тяжёлый крейсер 14×7) и две шутки по StarCraft II: «Гиперион» (линейный крейсер терранов) и «Гнев Айура» (авианосец протоссов). Отсеки для них лежат в «SkyPlane: отсеки StarCraft II».

При первом запуске ГМ получает папку «SkyPlane» с примером корабля «Альбатрос», его сценой и макросами, а в чат — ссылку на справку.

## API

```js
const api = game.modules.get("skyplane-combat-reverse").api;
await api.deployShip(ship);                    // Scene
await api.startBattle(leftShip, rightShip);    // Scene
await api.damageCompartment(ship, instanceId, 5);
await api.repairCompartment(ship, instanceId, { amount: 10 });
api.validateShip(ship);                        // { errors, warnings }
api.fireWeapon(ship, weaponInstanceId);        // прицел и обстрел от лица своего токена в пушке
api.scout(ship, reconInstanceId);              // проверка разведки
```

Полный список методов и хуков — в компендиуме «SkyPlane: справка», страница «Макросы и API».

## Разработка

Нужен Node.js 22 или новее. Один раз в папке модуля:

```bash
npm install
```

| Команда | Что делает |
|---|---|
| `npm run build` | CSS из SCSS, компендиумы из `packs/_source` в LevelDB, проверки |
| `npm run check` | Самопроверка правил корабля и сверка ключей `lang/ru.json` и `lang/en.json` |
| `npm run build:css` | Только CSS |
| `npm run build:packs` | Только компендиумы. Foundry держит базы открытыми, пока мир запущен: собирайте при остановленном мире |
| `npm run unpack` | Выгрузить компендиумы обратно в `packs/_source` — так правки, сделанные в Foundry, попадают в исходники |
| `npm run templates` | Отсеки StarCraft II и шаблоны кораблей; каждая раскладка проверяется правилами |
| `npm run placeholders` | SVG-заглушки отсеков по категориям и соотношениям сторон |
| `npm run package` | `build` и архив `../skyplane-combat-reverse.zip` без инструментов сборки и исходников компендиумов |

Источники правды: `packs/_source/*.json` (компендиумы), `lang/*.json` (тексты), `styles/*.scss` (стили). Скомпилированные `styles/*.css` и `packs/*` лежат в репозитории, чтобы модуль работал без сборки.
